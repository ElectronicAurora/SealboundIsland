对局设置与胜负

①单人混战：各自为战，全员相同 HP 上限，最后存活者胜。
②自定义分队：指定队伍，同队不能互相攻击（含陷阱），最后存活的队伍胜。
③BOSS 战：玩家 1 为 BOSS，HP = max(10, (人数−1)×10)，其余挑战者各 1 HP。

胜负判定：混战＝存活 ≤ 1 时结束；分队＝只剩一队时结束；BOSS 战按阵营判——BOSS 阵亡即英雄方获胜（不论还剩几名挑战者），挑战者全灭则 BOSS 胜，同归于尽为无人生还。不按存活人数判定。伤害结算后立即判胜负。

地图与移动

中心岛 + n 个外岛（n = 人数），星型相连：外岛只连中心岛，外岛之间不互通。每个外岛 3 个箱子，中心岛无限。移动 1 次走 1 格。传送器无视连接可去任意岛（被禁止移动时仍可用）。

击退沿「攻击者 → 目标」再推 1 格：目标在外岛 → 坠入虚空直接死亡；目标在中心岛 → 飞进另一侧外岛（不会是攻击者所在岛）。

战斗

伤害 = ATK − DEF，低于 0 无伤害（仍记 1 次【受击】）。每次被击打记 1 次受击。攻击目标可为玩家或召唤物。

武器：剑 +7；击退棒 ATK 0 但命中后击退 1 格；钓竿 ATK 0，射程 +1、命中后拉近 1 格，并可当道具钓鱼；弓箭 +8，蓄力 1 回合后射程 ∞；三叉戟 +9，近战无需蓄力，投掷需蓄力 1 回合、射程 ∞，投出后只能本人到落点岛捡回。

蓄力会被任何位移打断——主动的移动 / 开箱 / 传送，被动的被击退 / 被钓竿拉走，都算，需重新蓄力。

物品与掉落

HP ≤ 0 死亡，背包物品掉落在原地，下一个在该岛行动的玩家自动捡拾。坠入虚空例外：背包物品、投在外的三叉戟、布置的陷阱一并消失（已建成的炮台保留）。

刻印不入背包，死亡不掉落。召唤物是背包道具：未使用就阵亡会随掉落物留在原地，他人可拾获；已召唤的生物死亡直接消失。

附魔

回合外限 1 次，不占主要行动。自选一种附魔附加到指定某一件物品上（可附魔物品带独立编号 #N，给一把剑附魔不影响另一把）。不同附魔可叠加（锋利 + 轻盈 = ATK +3 且射程 +1）；同一种附魔在同一件物品上只能有一次。刻印、神器、附魔、传送器本身不能被附魔，因此不带编号。

锋利＝武器 ATK +3；坚固＝护甲 DEF +2；轻盈＝武器射程 +1；回响＝药水额外恢复 5 HP。

召唤物

使用「召唤物」道具后自选生物，出现在你所在的岛。在你的主要回合之后获得独立的召唤物回合，每只只行动 1 次：能打到就打，打不到就移动 1 步追击，绝不主动走进虚空。

召唤当回合不行动：刚召唤的生物「正在现身」，本回合的召唤物回合与召唤物额外回合都跳过（凌波给的额外行动也作废），从你的下一个回合起才行动；在额外回合里召唤的，本轮已过召唤物回合，下轮正常行动。

召唤师阵亡后保留原回合位继续行动；人头记给召唤师。DEF 恒为 0，可被攻击 / 击退 / 施加状态。没有⑩御灵时只能自动索敌（人类玩家也一样，不弹操控面板），且不享受召唤师刻印。召唤物不能被传送器传送。

机械（⑥天工）

「建造机械」消耗主要行动：构建炮台（当前岛，固定、无上限）／装填弹药（箭矢 8 ATK 单体、TNT 16 ATK 全岛，装填后弹药无限）／自动化（每主要回合开始前 TNT×1、箭矢×2）／手动发射（1 发）。

发射目标一律可自选：箭矢从全场敌方实体中选 1 个；TNT 从中心岛 + 全部外岛中选 1 个，该岛全部实体挨打（可以选自己所在岛）。每次都有「跳过」，跳过则不开火、手动发射不消耗主要行动。AI 自动索敌，不炸自己人，也不打没有敌人的岛。

发射视为「机械来源」攻击：不吃 ①劫雷 / ⑨裂帛 / ⑪点染。炮台不可被攻击。打光敌人立即结算，不再继续后续发射。

戒律（④敕禁）

每回合 1 次自由行动，对任一实体（玩家或召唤物）施加一条，持续到施加者下回合开始前：禁止攻击 / 禁止移动（传送器仍可用）/ 禁止开箱 / 禁止使用道具 / 禁止使用神器 / 禁止使用刻印主动能力。同类戒律不能叠加。

状态效果

【撕裂】每层在回合开始时（【尘】之前）扣 1 点真实伤害（无视 DEF）。【红】就是撕裂 +1 层，与 ⑨裂帛 走同一套层数相加。

【尘】每层减伤 1（含真实伤害），受到 1 点以上伤害即清空。【蓝】下次受击前无法攻击。【黄】使用药水前无法移动，最多 3 回合自动解除。【蓝】【黄】在受到攻击时解除。

结算顺序：回合开始 → 清空自己施加的旧戒律 → 炮台自动发射 → 撕裂 → 尘 → 黄兜底。

回合结构

主要回合（含回合开始结算与主要行动）→ 召唤物回合 → 召唤物额外回合 → 玩家额外回合 → 下一位玩家。

额外回合不再触发召唤物回合，也不重复结算回合开始效果。「谁的回合结算谁」：玩家在自己的主要回合开始结算自己的状态，召唤物在召唤物回合开始结算自己的。阵亡但有存活召唤物的玩家仍占回合位。

其他

神器：在当前岛布置陷阱，其他玩家（非同队）进入时受 3 点无视 DEF 伤害，触发即销毁；主动走入与被动落地都会触发。

技能：技能伤害不属于「攻击」——不计入受击次数，也不触发攻击类效果（击退、拉近、投掷等）。技能按钮暂未开放。

全游戏数值一律下取整。界面提供「强制结束」「返回主页面」，对局中随时可点开本规则，不影响回合状态。

开箱开出刻印，为什么背包里没有？

刻印是永久被动，开出即选立即生效，不占背包、不占回合、死亡不掉落，因此不会出现在「道具」列表里。

为什么选完刻印，回合就结束了？

开箱本身消耗了主要行动，选刻印的过程才是免费的。只有「回合开始捡拾」这类不消耗行动来源才是选完继续行动。

同一个刻印能选两次吗？

只有 ③丰穰 与 ⑧凌波（各分支）能叠加。其他刻印已拥有时再选会提示「重复不叠加」；一次性刻印全拿满后，面板只列出可叠加项，不会卡死。

只有 ⑧b 没有 ⑧a，闪避成功还能拿额外回合吗？

不能。⑧b 的 N 就是 ⑧a 的当前层数，⑧a 为 0 层时 ⑧b 完全不生效，一个额外回合都不给（没有保底）。想要追击流，得先叠 ⑧a。

蓄闪是不是按了就一定躲得掉？

是，下一次受击必定闪避，不看概率。但它只管攻击——【撕裂】、陷阱、坠入虚空照样掉血。

蓄闪之后按钮为什么是灰的？

两种情况：① 已经蓄着了，不能重复蓄；② 刚消耗完，冷却 1 轮，你下个回合仍然灰，再下一个回合恢复。玩家卡会显示「蓄闪」或「闪冷却」徽标。

中了「禁止使用刻印」，已经蓄好的闪会消失吗？

不会。蓄闪原样保留（不消耗、不解散），但戒律期间不能触发；戒律一解除，下一次受击立刻生效。

幽灵有 50% 闪避，被戒律封了刻印为什么还能闪？

幽灵的 50% 是生物固有特性，不是刻印效果，因此不受戒律影响。⑧a 的 30% 与蓄闪才是刻印效果，会被封掉。

弓箭为什么打不出去？

弓箭与三叉戟投掷都要先蓄力（占 1 个主要行动）。另外任何位移都会打断蓄力，包括自己移动、开箱、传送，以及被击退、被钓竿拉走。

三叉戟投出去，队友能帮我捡吗？

不能。只有投出的本人走到落点岛才会自动捡回，别人站上去也拿不走。

在外岛被击退会怎样？

直接死亡。外岛外面就是虚空，且背包物品、投在外的三叉戟、布置的陷阱会一并消失（已建成的炮台保留）。

护甲能叠加吗？捡了两件为什么只 +4 DEF？

默认不叠加，多件只按一件算（取附魔加成最高的那件）。拿到 ⑬盈箧 之后才按件数全叠加。

BOSS 死了我方还有好几个人，为什么直接结束了？

BOSS 战按阵营判定，不按存活人数。BOSS 一倒下，英雄方立即获胜。

炮台会误伤自己人吗？

TNT 会——命中该岛全部实体，包括自己、队友与召唤物。手动发射可以选择跳过或避开自己所在岛；AI 会主动避开自己人。

炮台能暴击、能附加撕裂吗？

不能。发射视为「机械来源」，不吃 ①劫雷 / ⑨裂帛 / ⑪点染。

炮台装填的弹药会用完吗？

不会。装填一次即弹药无限，之后只需决定自动化开关与何时手动发射。

召唤物刚召唤出来这回合为什么不动？

刚召唤的生物处于「正在现身」状态，当回合的召唤物回合与额外回合都跳过，从你的下一个回合起才行动。

怎么手动操控召唤物？

需要 ⑩御灵。没有 ⑩御灵时，无论人类还是 AI，召唤物都只能自动索敌，不会弹操控面板。

召唤物会跟着我换岛吗？

只有游侠会跟随（移动、传送、被打飞、被钓竿拉走都算）。巨兽与幽灵按自己的索敌逻辑行动。召唤物本身不能被传送器传送。

队友的陷阱会伤到我吗？

不会。分队模式同队陷阱不伤自己人。混战模式没有队友，人人都会中招。

物品后面的 #编号是什么意思？

只有能被附魔的物品（武器 / 护甲 / 药水）才有独立编号，因为附魔绑定到具体那一件。给一把剑附魔不会影响另一把剑。

附魔能叠加吗？占回合吗？

不同附魔可以叠加（锋利 + 轻盈 = ATK +3 且射程 +1），同一种在同一件上只能有一次。附魔是回合外行动，每回合限 1 次，用完还能继续主要行动。

对局卡住了 / 想重开怎么办？

界面上有「强制结束」与「返回主页面」。「强制结束」直接结算当前对局；「返回主页面」回到开局设置，可重新配置模式与人数。
