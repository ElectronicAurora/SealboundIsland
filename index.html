对局设置与胜负

①单人混战：各自为战，全员相同 HP 上限，最后存活者胜。
②自定义分队：指定队伍，同队不能互相攻击，最后存活的队伍胜。
③BOSS 战：玩家 1 为 BOSS，HP = max(10, (人数−1)×10)，其余挑战者各 1 HP。

胜负判定：混战＝存活 ≤ 1 时结束；分队＝只剩一队时结束；BOSS 战按阵营判——BOSS 阵亡即英雄方获胜（不论还剩几名挑战者），挑战者全灭则 BOSS 胜，同归于尽为无人生还。不按存活人数判定。伤害结算后立即判胜负。

地图与移动

中心岛 + n 个外岛（n = 人数），星型相连：外岛只连中心岛，外岛之间不互通。每个外岛 3 个箱子，中心岛无限。移动 1 次走 1 格。传送器无视连接可去任意岛（被禁止移动时仍可用）。

击退沿「攻击者 → 目标」再推 1 格：目标在外岛 → 坠入虚空直接死亡；目标在中心岛 → 飞进另一侧外岛（不会是攻击者所在岛）。

战斗

伤害 = ATK − DEF，低于 0 无伤害（仍记 1 次【受击】）。每次被击打记 1 次受击。攻击目标可为玩家或召唤物。

武器：剑 +7；击退棒 ATK 0 但命中后击退 1 格；钓竿 ATK 0，射程 +1、命中后拉近 1 格，并可当道具钓鱼；弓箭 +8，没有近战——必须先蓄力，1 回合后释放、射程 ∞；三叉戟 +9，近战无需蓄力，投掷需蓄力 1 回合、射程 ∞，投出后只能本人到落点岛捡回；遗器斩月 +11，近战无需蓄力，也可蓄力 1 回合后远程释放（射程 ∞，无需捡回）。

蓄力会被任何位移打断——主动的移动 / 开箱 / 传送，被动的被击退 / 被钓竿拉走，都算，需重新蓄力。

物品与掉落

HP ≤ 0 死亡，背包物品掉落在原地，下一个在该岛行动的玩家自动捡拾。坠入虚空例外：背包物品、投在外的三叉戟一并消失（已建成的炮台保留）。遗器是武器，随掉落物留在原地，他人可拾获。

刻印不入背包，死亡不掉落。召唤物是背包道具：未使用就阵亡会随掉落物留在原地，他人可拾获；已召唤的生物死亡直接消失。

附魔

回合外限 1 次，不占主要行动。自选一种附魔附加到指定某一件物品上（可附魔物品带独立编号 #N，给一把剑附魔不影响另一把）。不同附魔可叠加（锋利 + 轻盈 = ATK +3 且射程 +1）；同一种附魔在同一件物品上只能有一次。刻印、附魔、传送器本身不能被附魔，因此不带编号；遗器可被附魔（锋利 +3 ATK 等）。

锋利＝武器 ATK +3；坚固＝护甲 DEF +2；轻盈＝武器射程 +1；回响＝药水额外恢复 5 HP。

召唤物

使用「召唤物」道具后自选生物，出现在你所在的岛。在你的主要回合之后获得独立的召唤物回合，每只只行动 1 次：能打到就打，打不到就移动 1 步追击，绝不主动走进虚空。

召唤当回合不行动：刚召唤的生物「正在现身」，本回合的召唤物回合与召唤物额外回合都跳过（凌波给的额外行动也作废），从你的下一个回合起才行动；在额外回合里召唤的，本轮已过召唤物回合，下轮正常行动。

召唤师阵亡后保留原回合位继续行动；人头记给召唤师。DEF 恒为 0，可被攻击 / 击退 / 施加状态。没有⑩御灵时只能自动索敌（人类玩家也一样，不弹操控面板），且不享受召唤师刻印。召唤物不能被传送器传送。

机械（⑥天工）

「建造机械」消耗主要行动：构建炮台（当前岛，固定、无上限）／装填弹药（箭矢 8 ATK 单体、TNT 16 ATK 全岛，装填后弹药无限）／自动化（每主要回合开始前 TNT×1、箭矢×2）／手动发射（1 发）。

发射目标一律可自选：箭矢从全场敌方实体中选 1 个；TNT 从中心岛 + 全部外岛中选 1 个，该岛全部实体挨打（可以选自己所在岛）。每次都有「跳过」，跳过则不开火、手动发射不消耗主要行动。AI 自动索敌，不炸自己人，也不打没有敌人的岛。

发射视为「机械来源」攻击：不吃 ①劫雷 / ⑨裂帛 / ⑪点染。炮台不可被攻击。打光敌人立即结算，不再继续后续发射。

戒律（④敕禁）

每回合 1 次自由行动，对任一实体（玩家或召唤物）施加一条，持续到施加者下回合开始前：禁止攻击 / 禁止移动（传送器仍可用）/ 禁止开箱 / 禁止使用道具 / 禁止使用遗器技能（被动无视戒律）/ 禁止使用刻印主动能力（封 ④⑦⑥⑨b⑩b⑪b⑤b 主动技与商店交易；炮台自动发射算被动，不受此限）。同类戒律不能叠加。持有分支 4b【敕罚】时：每次成功敕禁给目标叠加 1 层【敕罚】，目标每次进行该行动后受 4×层数点真实伤害（同【撕裂】口径，多人同类禁合并成一次结算）；戒律到期后层数仍在（余罚残留）、无限持续，可被【灰】解除；施加者死亡或 ④/4b 被【黑】/卖出时其挂出的全部敕罚直接清除。

状态效果

【撕裂】回合开始时（【尘】之后、⑤b 爆发之后）一次性结算，公式：层数 + 施加者 ⑫b 的尘增伤 − 承受者的尘减伤（无视 DEF 与护盾）。逐层取施加者：撕裂会由不同人在不同时刻一层层挂上去，每一层按「挂上那一层的人」当时的 ⑫b 尘增伤计算，最后相加（无施加者来源的层按 0 增伤）。减伤只扣一次，取承受撕裂者自己的【尘】层数。【红】就是撕裂 +1 层，与 ⑨裂帛 走同一套层数相加。⑨b 拥有者施加的撕裂另有附加：每层令目标 DEF −1，DEF < 0 时无法移动（见 ⑨b 行）。

【尘】每层减伤 1（含真实伤害）—— 减伤是【尘】的固有属性，任何来源的尘层都减伤。攻击增伤是 ⑫b 分支的专属收益：只有持有 ⑫b 时，每层才同时为自身攻击提供 1 点 ATK 增伤（玩家卡显示「尘N（减伤N·增伤+N）」）；只有基础 ⑫、从【红】/ 御灵补到的尘层，都只减伤不增伤。受到 1 点以上伤害即清空，增伤随之消失。

【敕罚】（4b）：目标每次进行被禁的那类行动后结算 4×层数 真实伤害（+施加者⑫b尘增伤 − 承受者尘，无视 DEF/护盾、不走命中环节、不暴击）；同类合并成一次结算（不同人挂的同一禁类算一个效果，层数合计、伤害仍按各自施加者算），跨类各结一次；召唤物也会被戒律、也照常结算敕罚（它每做完一次行动当场结一次）。【蓝】下次受击前无法攻击。【黄】使用药水前无法移动，最多 3 回合自动解除（挨打不会解除，只有回合倒计时与喝药水两条路）。【蓝】【白】在受到攻击时解除。

结算顺序：回合开始 → 清空自己施加的旧戒律 → 炮台自动发射 → 尘 +1 → ⑤b 爆发 → 撕裂 → 黄兜底。

回合结构

主要回合（含回合开始结算与主要行动）→ 召唤物回合 → 召唤物额外回合 → 玩家额外回合 → 下一位玩家。

额外回合不再触发召唤物回合，也不重复结算回合开始效果。「谁的回合结算谁」：玩家在自己的主要回合开始结算自己的状态，召唤物在召唤物回合开始结算自己的。阵亡但有存活召唤物的玩家仍占回合位。

⑧b 凌波的插队回合：闪避往往发生在别人的回合，额度当场记下，但不会打断正在结算的那一击；等当前行动者这一整个回合结束后，立刻插入一个属于闪避者的额外回合（N 个就插 N 个），插完再回到原本的回合顺序。阵亡者或⑦蹑景被【黑】时，名下待插入的回合作废。

其他

⑬b 盈箧·商店：回合中可与商店交易，不限次数、不占主要行动。开局 0 金币，只能靠卖背包物品起家；买卖同价（刻印 10 / 遗器 10 / 剑·弓·三叉戟·钓竿·击退棒·护甲 各 5 / 药水·传送器 3 / 附魔 1）。卖刻印是永久删除：先按【黑】的口径做完整即时清算，且不回滚（详见 FAQ）。

遗器（4 选 1 特殊武器）

开箱 / 钓鱼 5% 获得，当场从 4 件中自选 1 件直接装备（不占回合），可重复获得（多件并存、⑬盈箧下 ATK 叠加）。遗器是武器：可被附魔、死亡掉落（虚空除外）。主动技消耗主要行动，属于「技能」：不走普攻的 ①劫雷 / ⑪点染判定，不触发击退 / 拉近等攻击类效果，可以在命中环节被闪避（沧溟的「吸收 HP」除外）；造成伤害时触发 ⑨裂帛、计入目标【受击】（被闪避则不计）。「真实伤害」只描述无视 DEF 与护盾，与能否闪避无关（详见下方 FAQ）。受戒律「禁止使用遗器技能」封禁，但沧溟 / 忘川的被动无视戒律。

技能与「受击」：被有伤害的技能打到也算受击（记次数、可叠加【撕裂】），技能与机械伤害同样走命中环节、可以被闪避，但不触发攻击类效果（击退、拉近、投掷等）。

全游戏数值一律下取整。界面提供「强制结束」「返回主页面」，对局中随时可点开本规则，不影响回合状态。

开箱开出刻印，为什么背包里没有？

刻印是永久被动，开出即选立即生效，不占背包、不占回合、死亡不掉落，因此不会出现在「道具」列表里。

为什么选完刻印，回合就结束了？

开箱本身消耗了主要行动，选刻印的过程才是免费的。只有「回合开始捡拾」这类不消耗行动来源才是选完继续行动。

同一个刻印能选两次吗？

只有 ③丰穰 与 ⑧凌波（各分支）能叠加。其他刻印已拥有时再选会提示「重复不叠加」；一次性刻印全拿满后，面板只列出可叠加项，不会卡死。

只有 ⑧b 没有 ⑧a，闪避成功还能拿额外回合吗？

选不了。⑧b 的 N 就是 ⑧a 的当前层数，没有分支①时分支②在分支面板里是灰的、点不了；即便拿到手，⑧a 为 0 层时 ⑧b 也完全不生效（没有保底）。想要追击流，得先叠 ⑧a。

蓄闪是不是按了就一定躲得掉？

是，下一次受击必定闪避，不看概率。它对攻击、技能伤害、机械伤害都生效（闪避属于命中环节，与伤害类型无关）——只有【撕裂】结算、坠入虚空、忘川均分这类非命中来源躲不掉。

蓄闪之后按钮为什么是灰的？

两种情况：① 已经蓄着了，不能重复蓄；② 刚消耗完，冷却 1 轮，你下个回合仍然灰，再下一个回合恢复。玩家卡会显示「蓄闪」或「闪冷却」徽标。

中了「禁止使用刻印」，已经蓄好的闪会消失吗？

不会。蓄闪原样保留（不消耗、不解散），但戒律期间不能触发；戒律一解除，下一次受击立刻生效。

幽灵有 50% 闪避，被戒律封了刻印为什么还能闪？

幽灵的 50% 是生物固有特性，不是刻印效果，因此不受戒律影响。⑧a 的 30% 与蓄闪才是刻印效果，会被封掉。

弓箭为什么打不出去？

弓箭与三叉戟投掷都要先蓄力（占 1 个主要行动）。另外任何位移都会打断蓄力，包括自己移动、开箱、传送，以及被击退、被钓竿拉走。

三叉戟投出去，队友能帮我捡吗？

不能。只有投出的本人走到落点岛才会自动捡回，别人站上去也拿不走。

在外岛被击退会怎样？

直接死亡。外岛外面就是虚空，且背包物品、投在外的三叉戟会一并消失（已建成的炮台保留）。

护甲能叠加吗？捡了两件为什么只 +4 DEF？

默认不叠加，多件只按一件算（取附魔加成最高的那件）。拿到 ⑬盈箧 之后才按件数全叠加。

BOSS 死了我方还有好几个人，为什么直接结束了？

BOSS 战按阵营判定，不按存活人数。BOSS 一倒下，英雄方立即获胜。

炮台会误伤自己人吗？

TNT 会——命中该岛全部实体，包括自己、队友与召唤物。手动发射可以选择跳过或避开自己所在岛；AI 会主动避开自己人。

炮台能暴击、能附加撕裂吗？

不能。发射视为「机械来源」，不吃 ①劫雷 / ⑨裂帛 / ⑪点染，但伤害走命中环节，可以被闪避。

炮台装填的弹药会用完吗？

不会。装填一次即弹药无限，之后只需决定自动化开关与何时手动发射。

召唤物刚召唤出来这回合为什么不动？

刚召唤的生物处于「正在现身」状态，当回合的召唤物回合与额外回合都跳过，从你的下一个回合起才行动。

怎么手动操控召唤物？

需要 ⑩御灵。没有 ⑩御灵时，无论人类还是 AI，召唤物都只能自动索敌，不会弹操控面板。

召唤物会跟着我换岛吗？

只有游侠会跟随（移动、传送、被打飞、被钓竿拉走都算）。巨兽与幽灵按自己的索敌逻辑行动。召唤物本身不能被传送器传送。

⑨b 的撕裂把 DEF 压到负数会怎样？

该实体无法移动。⑨b 拥有者施加的【撕裂】每层令目标 DEF −1（可累加，层数不清零就会一直压着）；当 DEF 被压到 < 0，移动按钮置灰、AI 与召唤物也不会走位。DEF 变负还会让打在它身上的攻击更痛（伤害要减 DEF）。传送器仍可用 —— 与戒律「禁止移动（传送器仍可用）」同口径，传送是道具、不走移动流程。想解除就用 ⑪b【灰】选中【撕裂】，层数和 DEF 惩罚一起清掉。

点染分支的【灰】能解什么？

【灰】不上状态、立即生效：选一个目标后，把他身上现有的效果逐项列出（【白】【黑】【蓝】【黄】【撕裂】【尘】【戒律】【敕罚】【蓄闪】），你选一个立即解除（【敕罚】按「目标×禁类×施加者」逐条整条解除）。解【黑】是「黑掉施加者⑪」之外的第二条解黑路径，且解除时 ⑩御灵的血上限会加回。目标身上没有任何效果时【灰】无事可做，会退回颜色选择，不消耗主要行动。

遗器技能会暴击 / 被闪避吗？

「真实伤害」与「能不能被闪避」是两件事：真实伤害只定义「无视 DEF 与护盾」，【尘】减伤照常生效；能否被闪避只看这一击走不走命中环节。七弦 / 斩月可以被闪避：造成伤害时计入受击并触发 ⑨裂帛，被闪避则都不触发；斩月被闪则斩杀落空，但 HP 减半的代价照付。沧溟的「吸收 HP」不走命中环节，不可被闪避。暴击方面：只看这一击是「攻击」还是「技能」，与是不是真实伤害无关：只有走「攻击」管线的普通攻击（含召唤物、残锋 5b 爆发）才吃 ①劫雷 2~20 倍暴击（① 2 层起必定）；遗器技能、七弦「连射」、沧溟「吸收 HP」、炮台机械伤害、【撕裂】结算都走「技能 / 非攻击」管线，一律不暴击 —— 哪怕它们是真实伤害。

忘川携带者被打到负 HP 会死吗？

不会。只有 HP 恰好为 0 才死亡，负 HP 仍存活，之后回血正常计算。

负血挨打时只会越扣越负（-3 挨 3 点 → -6），伤害永远推不到 0，所以负血不会因为受伤被「洗白回满」；代码里另有一道兜底，任何路径把负血写成 0 都会改写成 -1（下限 -1，不设更低）。但「赋值型」路径不受这条保护：均分把 HP 设为 0、斩月「斩杀」把 HP 置 0，都照样判死 —— 这些不是挨打，是直接改血。

卖掉忘川同样会当场判死。

沧溟的被动每回合都弹面板，能不做吗？

可以点「取消」放弃本次被动分配（点数浪费）。被动不占行动，即使被「禁止使用遗器技能」戒律封了主动技，被动画板照样出现（被动无视戒律）。

商店怎么用？金币从哪来？

需要 ⑬盈箧 的分支：已经拥有 ⑬ 之后再选一次 ⑬，在分支面板里选「盈箧·分支」即解锁商店。商店不限次数、不占主要行动，回合中随时可进出。开局 0 金币，只能先把背包物品卖成金币起家；买卖同价：刻印 10 / 遗器 10 / 剑·弓·三叉戟·钓竿·击退棒·护甲 各 5 / 药水·传送器 3 / 附魔 1。买刻印走「自选一项」、买遗器走「4 选 1」，与开箱同一条链路；装备中的物品卖出会自动卸下。

卖刻印会怎样？

永久删除，且不可回滚 —— 比【黑】更狠：【黑】是遮罩（刻印数据还在，撤掉遮罩就回来），卖出是真的把刻印抹掉。卖出瞬间会先按【黑】的口径做一次即时清算：④ 立即解除自己施加出去的全部戒律与敕罚（别人挂给你的戒律不动）、⑦ 作废已攒未兑现的额外回合、⑧ 已蓄的闪作废并重置冷却、⑩ 召唤物血上限回落并重判胜负、⑪ 清掉自己施加出去的全部白黑；卖的是基础项时，名下分支一并消失。所以「拿 ④ 解完戒律马上卖掉换钱」这类白嫖不成立。

卖出后仍然保留：自动炮台（已建好的照常运作，只是不能再新建）、【撕裂】【红】【黄】【蓝】【尘】—— 这些是既成事实：刻印只是当初把它们挂上去，挂上之后就是目标自己的状态，不存在「由哪枚刻印持续供给」的关系，所以卖刻印不会把它们清掉，卖 ⑫ 尘梦也不会清掉已有的【尘】层数。

被【黑】的刻印照样能卖：【黑】只是遮罩，刻印数据还在，判定「有没有这一项」只看数据本身（不看黑）。卖掉即真删，卖掉之后【黑】那条记录仍留在身上（它记的是「谁黑了你哪一项」），但已经没有可删的刻印了。

卖掉【遗器·忘川】会当场判死吗？

会。忘川的「不死」是查询时实时判（每次死亡检查都去背包里看这件遗器在不在），不是获得时打上的标记 —— 所以遗器一离手，「不死」立刻失效。卖出忘川时如果 HP ≤ 0，当场阵亡，不必等下一次挨打；阵亡后按正常流程掉落背包（此时忘川已经卖掉了，不在掉落里）。HP > 0 时卖只是退掉保险，人没事。
顺带一提：负血的下限是 -1 —— 负血者再受伤害永远不会被打到 0（也就不会因为「恰好为 0」而死，还白送回满血），最低停在 -1，回血才往上走。

物品后面的 #编号是什么意思？

只有能被附魔的物品（武器 / 护甲 / 药水 / 遗器）才有独立编号，因为附魔绑定到具体那一件。给一把剑附魔不会影响另一把剑。

附魔能叠加吗？占回合吗？

不同附魔可以叠加（锋利 + 轻盈 = ATK +3 且射程 +1），同一种在同一件上只能有一次。附魔是回合外行动，每回合限 1 次，用完还能继续主要行动。

对局卡住了 / 想重开怎么办？

界面上有「强制结束」与「返回主页面」。「强制结束」直接结算当前对局；「返回主页面」回到开局设置，可重新配置模式与人数。

AI 会把【尘】叠到打不动人吗？它怎么办？

【尘】每层减伤 1，⑫尘梦在中心岛（箱子无限）可以一直叠。AI 现在扣掉尘之后仍打不出伤害就不再攻击，改走三条通道：① 沧溟【分配】（真实伤害、逐点结算、不看 DEF，只要「点数 + 自身 ⑫b 尘」> 对面尘层就能打穿）→ ② 弓箭蓄力释放（无限射程，可隔岛点名）→ ③ 开箱找沧溟 / 找 ④、⑨b 刻印。不会再对着厚尘做 0 伤害攻击（旧版会，曾导致 17 回合超时）。

「AI 经验库」是什么？会上传我的数据吗？

AI 会把打过的局记成几个计数器（开箱 / 蓄力 / 先拆最痛的 / 破壁 四项的胜负次数），用来微调自己的决策倾向，最多只调 ±25%，不改任何规则。
数据只存在你自己浏览器的 localStorage 里，不联网、不上传、不存棋谱，整份存档实测约 213 字节、不随局数增长。清掉浏览器数据即彻底删除。结算面板会显示四项的胜率与权重，一局都没学到时整块隐藏。
